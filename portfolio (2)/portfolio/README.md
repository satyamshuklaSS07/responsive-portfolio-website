# Responsive Personal Portfolio Website

A responsive portfolio with Home, About, Skills, Projects, Education/Experience and Contact sections.

## Tech
HTML5, CSS3 (Flexbox + Grid, media queries), vanilla JavaScript, Git/GitHub.

## Features
- Semantic HTML5 (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Responsive layout for desktop, tablet (≤860px) and mobile (≤640px)
- Hamburger navigation menu on small screens
- Contact form with JavaScript validation
- Keyboard focus styles, skip link, reduced-motion support

- 3D hero scene (three.js from CDN), rotating CSS 3D cube, tilt-on-hover project cards
- Dark theme with scroll, typing and reveal animations

## Run locally
Needs internet once (Google Fonts and three.js load from CDN). Open `index.html` in a browser, or use the VS Code "Live Server" extension.

## Customize
1. Replace "Alex Morgan" and the placeholder text in `index.html`.
2. Update project links to your GitHub repos.
3. Change colors in the `:root` block of `style.css`.

## Deploy
Push to GitHub, then enable **Settings → Pages** on the main branch.
